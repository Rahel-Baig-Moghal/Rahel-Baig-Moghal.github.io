Privacy Policy — Fahm: Quranic Vocabulary

Effective Date: October 17, 2026 · Package ID: com.rahel.fahm

Compliance Declaration: Fahm: Quranic Vocabulary operates entirely offline on your local device. The application does not collect, store, transmit, or share any personal user data, device identifiers, or usage telemetry.

1. 100% Offline Architecture & Zero Data Collection

Fahm: Quranic Vocabulary ("the App", package identifier com.rahel.fahm) is developed and published by Rahel Baig Moghal.

  • No Network Permissions: The App requests zero network access. Specifically, android.permission.INTERNET is explicitly blocked in the production Android manifest.
  • No Personal Information Collected: We do not collect, request, store, transmit, or share any personally identifiable information (PII), account credentials, location coordinates, or device identifiers.
  • No Third-Party SDKs or Advertising: The App integrates zero third-party analytics trackers, crash reporting agents, or advertising networks.

2. Local On-Device Storage & User Sovereignty

All study records, level completions, daily streaks, spaced-repetition schedules, and user preferences are stored strictly on your device inside a local SQLite database file (user_progress.db).

  • Backup & Restore: Users may voluntarily export or import their progress as a local JSON file using the operating system's native document picker.
  • Data Deletion: Users can permanently purge all progress via the in-app Profile reset control, by clearing application storage in Android system settings, or by uninstalling the App.

3. Local Notifications

If enabled by the user, daily study reminders are scheduled strictly on-device via the local operating system alarm manager. No external push notification servers (such as FCM) or remote network tokens are utilized.

4. Children's Privacy (COPPA & Google Play Families Policy)

The App is an educational tool suitable for learners of all ages. Because the App collects zero personal data, displays zero advertisements, and performs zero network communication, it complies fully with the Children's Online Privacy Protection Act (COPPA) and the Google Play Families Policy.

Frequently Asked Questions
Does Fahm require an internet connection?
No. android.permission.INTERNET is blocked at the manifest level. All 170 vocabulary levels and linguistic roots are packaged inside the application binary.
Where is my learning progress stored?
Progress is stored strictly on your device inside the local SQLite database (user_progress.db). Nothing is ever uploaded to a remote server.
How do I transfer my progress to a new phone?
Open the Profile tab in Fahm and select Export Backup to save a JSON file to your device storage. On your new phone, use Import Backup to restore your state.
How do I report a linguistic correction or bug?
Send an email to rahelbaig1@gmail.com with the level number, word entry, and details of the issue.
