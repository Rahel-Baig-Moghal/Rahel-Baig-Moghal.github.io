# Rahel Baig Moghal — Engineering Portfolio & Applications

Personal portfolio website and official documentation repository for **Rahel Baig Moghal**, showcasing cloud contact center architecture, serverless infrastructure, and offline-first mobile software.

🌐 **Live Website:** [https://rahel-baig-moghal.github.io/](https://rahel-baig-moghal.github.io/)

---

## 🚀 Overview

This repository hosts the static single-page application (SPA) deployed via GitHub Pages, featuring:

- **Engineering Disciplines & Systems:** Highlights production systems built on AWS Serverless (Lambda, DynamoDB, API Gateway, SAM) and Amazon Connect contact flows with Amazon Lex conversational AI.
- **Fahm (Quranic Vocabulary):** Product specification, architectural principles, and core features for *Fahm* (`com.rahel.fahm`), an offline-first learning companion structured into 170 retention levels.
- **Privacy Policy & Play Store Compliance:** Google Play Store compliant data safety and privacy documentation for *Fahm*.
- **Support & FAQ:** Direct support channels, user FAQ, and terms of service.

---

## 🛠️ Technology Stack

- **Structure & Style:** Semantic HTML5 and Vanilla CSS (custom design system, responsive grid/matrix layouts, dark palette).
- **Client Logic:** Vanilla JavaScript for client-side routing, tab switching, and hash-based deep linking.
- **Hosting:** GitHub Pages with custom routing (`#portfolio`, `#fahm`, `#privacy`, `#support`).
- **Dependencies:** Zero external dependencies or build tools required.
