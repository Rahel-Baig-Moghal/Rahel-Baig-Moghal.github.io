## 🚀 Architectural Highlights & Showcase

This repository hosts the static single-page application (SPA) deployed via GitHub Pages, featuring:

### 1. Featured Mobile Product: Fahm (فهم)
- **Tagline:** Offline-First Quranic Vocabulary Engine
- **Target:** Android (`com.rahel.fahm`) & iOS
- **Architecture:** 100% air-gapped mobile learning engine with manifest-level blocked network permissions (`android.permission.INTERNET` removed), on-device SQLite database (`user_progress.db`), native JSON backup/restore, and 170 progressive mastery levels synthesized via high-leverage LLM pipelines (Gemini Argon sprint).

### 2. Enterprise Cloud Architecture: Relay
- **Tagline:** Multi-Account Control Plane & CI/CD Engine for Amazon Connect
- **Architecture:** Enterprise orchestration platform resolving cross-environment contact flow deployment (Dev &rarr; Staging &rarr; Prod) with zero long-lived credentials via short-lived AWS STS `AssumeRole` discovery/mutation roles, S3-versioned artifact snapshots, DynamoDB single-table control plane, and automated Step Function rollback.

### 3. Developer Tooling & Agent Systems: tools-for-pi
- **Tagline:** Modular Agent Harness Extensions & Local Workflow Tooling
- **Architecture:** Modular tooling for local agent harnesses (the Pi coding agent) featuring compile-time type-safe TypeBox tool declarations, autonomous OAuth2 refresh token lifecycles (Google Calendar API), and a hybrid AI workflow pairing local LLMs (Qwen/Spark 4B via Ollama on Arch Linux) with frontier models (Gemini Flash/Argon).

### 4. Specialized Domain: Enterprise Cloud Contact Center & Telephony Engineering
- **Track Record:** Software Development Engineer at AMCONNECTGEN (transitioning to Neuraflash); recipient of the &ldquo;Jack of All Trades&rdquo; engineering award.
- **Competencies:** Intelligent skills-based routing, Amazon Lex conversational IVR with low-latency AWS Lambda fulfillment, custom agent workspaces, CRM CTI integrations (Salesforce & Zendesk), and enterprise case studies (Contact Center Builder, Surecall Amtelco migration, Serve7 99.9% uptime).

### 5. Personal Engineering Ethos
- **Radical Local-First & Data Sovereignty:** Applications should run without an internet tether, storing data where it belongs: on the user's silicon.
- **Industrial Pragmatism:** Prioritizing zero-dependency, durable software over bloated frameworks.
- **Hybrid AI Mindset:** Instant private local loops paired with high-order frontier models.
